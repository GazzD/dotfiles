# 🔒 Security Notes - Dotfiles Configuration

## Template Variables

This dotfiles repository uses **chezmoi templates** to manage sensitive information safely.

### Required Variables

On first run, chezmoi will prompt you for the following values:

| Variable | Purpose | Example |
|----------|---------|---------|
| `email` | Git configuration email | your.email@example.com |
| `name` | Git user name | Your Name |
| `monitor_layout` | Hyprland monitor setup (Linux only) | dual/single/laptop |
| `google_calendar_client_id` | Google Calendar OAuth2 Client ID | xxxxx.apps.googleusercontent.com |
| `google_calendar_client_secret` | Google Calendar OAuth2 Client Secret | GOCSPX-xxxxxxxxxxxxxxx |
| `openweathermap_api_key` | OpenWeatherMap API key | xxxxxxxxxxxxxxxxxxxxxxx |
| `spotify_client_id` | Spotify API Client ID | xxxxxxxxxxxxxxxxxxxxxxx |
| `weather_latitude` | Weather widget location latitude | 40.4168 |
| `weather_longitude` | Weather widget location longitude | -3.7038 |

### Getting API Keys

#### Google Calendar (for calcurse sync)
1. Go to [Google Cloud Console](https://console.cloud.google.com/)
2. Create a new project
3. Enable "Google Calendar API"
4. Create OAuth2 credentials
5. Add `http://127.0.0.1` as redirect URI

#### OpenWeatherMap (for waybar weather widget)
1. Sign up at [OpenWeatherMap](https://openweathermap.org/)
2. Go to API Keys section
3. Generate a new API key (free tier available)

#### Spotify (for spotify-player TUI)
1. Go to [Spotify Developer Dashboard](https://developer.spotify.com/dashboard)
2. Create a new app
3. Copy the Client ID
4. Add `http://127.0.0.1:8989/login` as redirect URI

### Templated Files

The following files use templates to inject secrets safely:

- `.gitconfig` - Uses `{{ .email }}` and `{{ .name }}`
- `dot_config/calcurse/caldav/config` - Uses OAuth2 credentials
- `dot_config/waybar/scripts/weather.sh` - Uses API key
- `dot_config/spotify-player/app.toml` - Uses Spotify client ID

### Security Best Practices

✅ **Do:**
- Store this repo in a public/private Git repository
- Run `chezmoi apply` to deploy configs safely
- Use `chezmoi edit <file>` to modify templated files

❌ **Don't:**
- Commit actual secrets to the repository
- Share your `~/.config/chezmoi/chezmoi.toml` file (contains actual values)
- Remove `.tmpl` extension from sensitive files

### Files Automatically Ignored

The `.chezmoiignore` file excludes:
- OAuth2 tokens (auto-regenerated by apps)
- Browser data with sensitive keys
- SSH/GPG private keys
- Shell history files
- Application caches and state databases

---

**Note**: After initial setup, your secrets are stored in `~/.config/chezmoi/chezmoi.toml` (local only, never committed).
